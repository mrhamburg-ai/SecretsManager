# SecretsManager.AliyunKms

Alibaba Cloud KMS secret provider

## Usage

```csharp
// Add the SecretsManager.AliyunKms secret provider to your configuration
services.AddSecretsManager()
    .AddAliyunKms();
```

## Installation

```bash
dotnet add package SecretsManager.AliyunKms
```
