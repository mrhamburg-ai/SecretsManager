# SecretsManager.OracleVault

Oracle Vault secret provider

## Usage

```csharp
// Add the SecretsManager.OracleVault secret provider to your configuration
services.AddSecretsManager()
    .AddOracleVault();
```

## Installation

```bash
dotnet add package SecretsManager.OracleVault
```
