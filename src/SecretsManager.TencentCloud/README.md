# SecretsManager.TencentCloud

Tencent Cloud secret provider

## Usage

```csharp
// Add the SecretsManager.TencentCloud secret provider to your configuration
services.AddSecretsManager()
    .AddTencentCloud();
```

## Installation

```bash
dotnet add package SecretsManager.TencentCloud
```
