# SecretsManager.OVH

OVH Secrets Manager provider

## Usage

```csharp
// Add the SecretsManager.OVH secret provider to your configuration
services.AddSecretsManager()
    .AddOVH();
```

## Installation

```bash
dotnet add package SecretsManager.OVH
```
