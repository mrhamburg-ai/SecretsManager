# SecretsManager.IBMCloudSecretsManager

IBM Cloud Secrets Manager provider

## Usage

```csharp
// Add the SecretsManager.IBMCloudSecretsManager secret provider to your configuration
services.AddSecretsManager()
    .AddIBMCloudSecretsManager();
```

## Installation

```bash
dotnet add package SecretsManager.IBMCloudSecretsManager
```
