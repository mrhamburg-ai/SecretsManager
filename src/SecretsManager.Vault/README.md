# SecretsManager.Vault

HashiCorp Vault secret provider

## Usage

```csharp
// Add the SecretsManager.Vault secret provider to your configuration
services.AddSecretsManager()
    .AddVault();
```

## Installation

```bash
dotnet add package SecretsManager.Vault
```
