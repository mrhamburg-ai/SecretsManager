# SecretsManager.PostgreSql

PostgreSQL secret provider

## Usage

```csharp
// Add the SecretsManager.PostgreSql secret provider to your configuration
services.AddSecretsManager()
    .AddPostgreSql();
```

## Installation

```bash
dotnet add package SecretsManager.PostgreSql
```
