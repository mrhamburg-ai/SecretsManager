# SecretsManager.Scaleway

Scaleway secret provider

## Usage

```csharp
// Add the SecretsManager.Scaleway secret provider to your configuration
services.AddSecretsManager()
    .AddScaleway();
```

## Installation

```bash
dotnet add package SecretsManager.Scaleway
```
