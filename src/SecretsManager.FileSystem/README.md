# SecretsManager.FileSystem

File system secret provider

## Usage

```csharp
// Add the SecretsManager.FileSystem secret provider to your configuration
services.AddSecretsManager()
    .AddFileSystem();
```

## Installation

```bash
dotnet add package SecretsManager.FileSystem
```
