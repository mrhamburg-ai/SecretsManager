# SecretsManager.Conjur

Conjur secret provider

## Usage

```csharp
// Add the SecretsManager.Conjur secret provider to your configuration
services.AddSecretsManager()
    .AddConjur();
```

## Installation

```bash
dotnet add package SecretsManager.Conjur
```
