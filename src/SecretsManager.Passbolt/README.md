# SecretsManager.Passbolt

Passbolt secret provider

## Usage

```csharp
// Add the SecretsManager.Passbolt secret provider to your configuration
services.AddSecretsManager()
    .AddPassbolt();
```

## Installation

```bash
dotnet add package SecretsManager.Passbolt
```
