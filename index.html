Why SecretsManager?

A modern approach to secret management in .NET

Unified API

Get, put, version, and delete secrets with one interface, regardless of the backend.

Multi-Provider

Swap between Azure, AWS, GCP, Scaleway, PostgreSQL, OVH, Passbolt, Tencent Cloud, HashiCorp Vault, CyberArk Conjur, or encrypted local files without changing your business logic.

Zero Bloat

Modular design. Only install the NuGet packages for the providers you actually use.

Versioning

First-class support for secret history across all providers.

JSON Extraction

Query nested JSON values directly via dot-path syntax.

Flexible Config

Configure via Fluent API, Environment Variables, or ESO-style YAML.

Configure Your Way

Choose the configuration style that fits your workflow

  • Fluent API
  • Environment
  • YAML
Program.cs
var provider = new SecretProviderBuilder()
    .WithFileSystem(options =>
    {
        options.BasePath = "/etc/secrets";
        options.EncryptionKey = "my-encryption-key";
    })
    .Build();

var secret = await provider.GetSecretAsync("db-password");
Console.WriteLine(secret.Value);
Terminal
export SECRETS_PROVIDER=filesystem
export SECRETS_FILESYSTEM_PATH=/etc/secrets
export SECRETS_FILESYSTEM_ENCRYPTION_KEY=my-key

// In your C# code:
var provider = new SecretProviderBuilder()
    .WithFileSystem()
    .FromEnvironment()
    .Build();

var secret = await provider.GetSecretAsync("db-password");

var provider = new SecretProviderBuilder()
